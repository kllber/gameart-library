① 先绑定你的 Steam Web API

读取你 Steam 账号拥有的游戏，并读取本机 Steam 数据以写入自定义封面。API 可免费在 Steam 内申请，本软件可绑定多个账号的 API。

② 再绑定你的 SteamGridDB API

搜索并下载游戏封面 / 横向封面 / 大背景 / Logo / 图标等艺术作品。API 可免费在 SteamGridDB 官网申请，如没有其账号请先自行在官网登录。

③ 最后添加游戏到你的艺术库

从 Steam 库添加现有封面，或手动添加游戏后从 SteamGridDB 挑选封面。

从 Steam 库添加

搜索添加

搜索游戏 → 从 SteamGridDB 挑选封面 → 加入你的库

设置

语言

语言选择会保存，界面文案将逐步补齐。

选「简体中文」会显示游戏的中文名（从 Steam 商店获取并缓存）；没有中文名的仍显示英文。

仅在需要时手动执行，不会影响启动速度。

个性化

「自动播放」会让主页的动图封面一直循环播放（只播屏幕内的、并限制同时播放数量）。动画很多仍觉得卡时，可切「悬停才播放」。

为库里已有的动图补齐预览文件（需要 SteamGridDB API Key），之后主页即可流畅播放。

SteamGridDB API

用途：搜索并下载游戏封面 / 横向封面 / 大背景 / Logo / 图标等艺术作品。需要你自己的 SteamGridDB API Key（免费申请）。

↗ 申请 SteamGridDB API Key

登录 SteamGridDB（Steam 账号）→ Preferences → API → 填个域名 → Generate。

有些公司网络或抓包代理用自己的证书，会让下载图片报「self signed certificate」。勾选后遇到该情况会回退为不校验证书（仅用于抓取 SteamGridDB 的公开图片，不涉及账号密码）。默认已勾选。

Steam 账号（Web API）

用途：读取你拥有的游戏（用于「从 Steam 库添加」），并读取本机 Steam 数据以写入自定义封面。需要 Steam Web API Key，且账号「游戏详情」设为公开。

已绑定

↗ 申请 Steam Web API Key

需在各账号 Steam「隐私设置 → 游戏详情」设为公开，否则同步不到游戏。

为库里「还没有图」的游戏补上 Steam 默认图；中途关掉软件也没关系，下次打开该库会自动继续。

本软件的数据与缓存都放在一个独立的数据目录里，不会散落到系统其它位置。

双击 .gameart 文件即可用本软件打开该库（默认已自动关联；也可在此取消或重新关联）。

—

缓存/临时文件都在上面的数据目录内，可用按钮释放空间；清理缓存/备份不影响 .gameart 库里的艺术作品。
