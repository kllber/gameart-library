游戏艺术库 · GameArt Library（便携分发版）
================================================

怎么用
------
1. 双击本文件夹里的「游戏艺术库.exe」即可启动（自带图标，无需安装任何东西）。
2. 首次打开会让你「打开 / 新建」一个 .gameart 库文件（就是你保存艺术作品的那个文件）。
3. 想要封面：先在 设置 里填你自己的 Steam Web API Key 和 SteamGridDB API Key。

无需安装
--------
- 本软件把运行环境（Electron）打包在本文件夹的 runtime 里，
  在 64 位 Windows（Win10/11）上开箱即用，不需要安装 Node.js 或其它依赖。
- 网络不依赖任何云端服务器；所有数据都在你自己电脑上。

数据都放在本文件夹（不写 C 盘）
--------------------------------
- data\      ：程序数据（最近打开、默认图缓存、同步前备份、以及 Electron 的缓存）
- tmp\       ：临时文件（同步/下载用，会自动清理）
- 你的 .gameart 库文件放在哪里由你决定（也可以放在本文件夹里）。
- 整个文件夹可以随意复制、搬到 U 盘、发给别人；想彻底卸载，删掉整个文件夹即可。

同步到 Steam（安全说明）
------------------------
- 本软件只把图片写入 Steam 的 userdata\<账号>\config\grid 目录（等于 Steam 自带"设置自定义图片"），
- 不注入、不修改 Steam 程序或内存；覆盖前会把原图备份到 data\backup\。

声明
----
- 与 Valve / SteamGridDB 无任何关联；游戏封面/Logo 等素材版权归各自作者所有。
- 本软件本身不提供任何艺术作品，素材来自你自己账号的 SteamGridDB API 与 Steam CDN。
- 请勿将包含他人素材的素材用于再分发或商业用途。
