游戏艺术库 · GameArt Library — 更新日志
================================================

v1.2.1  2026-10-11
- 【性能/严重】修 **「打开设置 / 点清理缓存会卡死好几秒」**：真凶是后端在**主进程里**
  跑了两件重活 —— ①「库内艺术图占用」的统计用了整表 `SUM(LENGTH(data)) GROUP BY type`，
  实测 **2.6~3.4 秒**（改成按类型逐条查只要 **27ms**）；②目录占用统计/清理用的是**同步**
  文件遍历（备份多时可能几万个文件）。现在改为：逐类型查询 + 异步 + 30 秒缓存 +
  设置面板"先显示再取数"。**实测 3.4 秒 → 67ms**，并且不再拖慢其它请求。
- 【性能】图片接口（封面/预览/默认图）**加上浏览器缓存头**。以前滚动或切换显示时浏览器
  会把几百张图**反复重新下载**（库里有单张几十 MB 的大图）→ 现在第二次滚动 **0 个新请求**，
  帧耗时从明显卡顿降到 **平均 7.5ms**（也顺带解决了滚动时的闪烁）。
- 【性能】Windows 上读取 Steam 安装路径（注册表）改成**异步 + 启动时预取**，
  Steam 游戏列表解析也**预热到启动阶段**，不再等用户点开设置时才卡。
- 【体验】「从 SteamGridDB 添加」以前要**先联网（1~2 秒）才出现选图界面**；现在**立刻弹出**
  并显示「正在定位 SteamGridDB 游戏…」，定位结果还会缓存（第二次 3ms 就出来）。
- 【观感】修 **横向封面上下的大黑边**：卡片比例改成与 Steam 横向网格一致的 **460:215**
  并**填满卡片**（不再留边）。
- 【观感】修 **透明底 + 纯黑内容 的 Logo/图标"看不见"**：卡片/详情/选图的**底色由近黑
  改为深灰**（深色主题 `#262a33`，浅色主题仍是浅灰），黑 Logo 现在清晰可见。
- 【性能】切换「显示」类型（竖版/横版/大背景/Logo/图标）不再整页重建，改为**只换封面**，
  切换几乎瞬时；并修掉"快速连点会被上一步的结果覆盖"的小毛病。
- 【性能·全屏复测】按你要求把窗口**最大化到 2560×1417** 复测：主网格上原来的
  `content-visibility` 反而拖慢（滚动平均 17ms、4 帧掉帧），**去掉它并改用 `contain`
  （外观完全不变）后降到 7ms、0 掉帧**；侧栏毛玻璃保留不动。当前**暖滚动基线：
  竖版/横版/Logo 中卡 7~9ms/帧、0 掉帧**（≈140fps）；图标/小卡一次显示 50 多张时
  约 13~16ms/帧（≈60fps）。剩下偶发尖峰来自"超大原图首次解码"（大背景模式实测
  一帧 536ms，你库里有单张几十 MB 的大图）——要根治需要做"显示用缩略图"，等你定。
- 顺带：`content-visibility` 占位高度按显示类型给准（滚动更稳）；英文界面里"存储占用"
  不再夹中文括号。
- 【新功能】**「显示用缩略图」**（可在 设置 → 库文件 关掉）：为大图生成"显示用缩略图"，让
  浏览与滚动更顺滑。缩略图**只放在缓存目录**（不动你库里的原图，可随"清理缓存"一键清掉，
  之后会自动重建）。生成过程**没有任何"待办状态"**：中途关掉软件，下次打开自动继续补齐；
  而且**你一操作（滚动/点击）它就让路**，不会和你抢流畅度。实测：大背景模式下的
  冷滚动峰值从 **536ms 降到 52ms**；**卡片调到最大也不会模糊**（按卡片实际像素×屏幕缩放
  请求，且**绝不放大**原图）。

v1.2.0  2026-10-11
- 新增 **「显示」下拉**（主页顶栏）：可选择卡片展示哪种艺术作品 —— 竖向封面 / 横向封面 /
  大背景 / Logo / 图标，卡片形状与列数会跟着自动调整（以前只能显示竖向封面）。
- 新增 **分类拖拽排序**：侧栏里的分类可以直接**按住鼠标上下拖**来调整顺序（不用开面板）。
- 新增 **批量分组**：`Ctrl` 多选几款游戏后**右键 → 更改分组**，可一次把它们**加入**同一个分类
  （只做"加入"，各游戏原有的分类不受影响）。
- 设置 → 库文件 新增 **「库内艺术图占用」明细**（各类型张数与占用），一眼看清"库为什么这么大"。
- Steam 账号页文案更正（Web API Key 与账号的关系、"可同时绑定多个账号"的说明）。
- 顺带：`.svg` 现在按正确 MIME 类型提供。

v1.1.0  2026-10-11
- 界面优化：
  · 「同步到 Steam 库」按钮改为**主题色**（跟随「个性化 → 强调色」）；
  · 左下角「游戏名同步」改名为「**中文名同步**」；
  · 「默认图同步」「中文名同步」右侧各加一个 **⟳ 快捷按钮**：点一下立刻开始，
    同步过程中图标会转圈，**不用再打开设置**；
  · 设置里的「切换 / 打开其他库文件」**挪到左栏底部**，打开设置一眼就看到。
- Linux 改为**绿色便携**：数据与缓存都放在**程序所在文件夹内**（`data/`、`tmp/`），
  **整个文件夹可以随意移动**，软件会自动跟随；旧版放在 `~/.local/share/gameart-library`
  的数据**首次运行会自动搬过来**（搬不动则留在原地，不影响使用）。
- 彻查并同步修正：中英文文案、深/浅主题下新按钮的可见性、缓存/临时文件位置等。
- 修复：**中文名同步总是"0/20 重来"** —— 那 20 款在 Steam 商店确实没有中文名，以前每次都会重新请求；
  现在会**记住"商店没有"**（下次跳过，只重试网络失败的），并在设置里显示"N 款商店暂无中文名（已跳过）"。
- 修复：**点完"默认图同步"退出软件后，重开看不出它在继续** —— 其实后台已经在续跑，只是界面没显示；
  现在状态栏会显示「**待续 N**」并持续观察，任务一启动就显示进度（`x/y` + 图标旋转）。
- 状态面板布局按反馈调整：**⟳ 按钮紧跟文字、数值靠右对齐**。

v1.0.1  2026-10-11
- 修复「默认图同步跑到一半关掉软件，再打开不会继续」：补全队列现在**存在库里**，
  关掉软件后再打开会**自动接着做**（完成一个记一个，不丢进度）。
- 修复「新建库后『从 Steam 库添加』导入的游戏很多没有名字、只显示 AppID」：
  取名字时会用 **Steam 提供的游戏名**（之前只查了本机数据）；并且打开旧库时
  会**自动把缺名字的游戏补上**（不用删掉重新导入）。
- 以上两个修复 **Windows 与 Linux 都包含**（问题与平台无关，只是不一定每次都遇到）。
- 新增：设置 → **库文件** 里加了「**补全默认图（后台）**」按钮（之前这个功能在界面上没有入口）。

v1.0.0  2026-10-10
- ★ **正式支持 Linux**（SteamOS / Bazzite / Fedora / Ubuntu 等，桌面模式运行）。
  Linux 版与 Windows 版功能对齐：封面 / 横向封面 / 大背景 / Logo / 图标 一键写入 Steam、
  多账号、中英双语、深/浅主题、自定义排序、回收站、缓存清理等。
- **`.gameart` 库文件在两个系统之间完全通用**（同一个文件直接复制即可，格式一致）。
- Linux 分发形式改为 **`.tar.gz`**：解压得到一个名为 **「游戏艺术库」** 的文件夹，
  里面带**启动器（显示软件名与图标）**、程序本体、图标与使用说明；**解压后双击启动器即可运行**，
  不需要敲命令、不需要安装、不需要 root。
- **第一次运行**会询问是否**创建桌面快捷方式**；之后开始菜单里也会出现「游戏艺术库」（可右键固定到任务栏）。
- Linux 下 **`.gameart` 文件关联默认自动完成**，并带**专属文件图标**（双击库文件即可打开）。
- 修复：官方 Steam 游戏的**图标**之前一直改不了（原来写错了位置，现在正确写入 Steam 的图标缓存；
  注意图标需要**重启一次 Steam** 才显示）。此修复 Windows / Linux 同样有效。
- 修复：删除某张艺术图后，仍提示「这张图已加入库」而无法重新添加（改为按**实时库数据**判断）。
- 版本号统一为 **1.0.0**（Windows 与 Linux 为同一版本）。

- 详情弹窗关闭后会清理状态；搜索时禁用自定义排序与拖拽。
- 修复"从选图器加完图、回到详情页看不到新图"：关闭选图器会立即刷新详情页（无需重启）。
- 选图器里已加入的图会显示「已加入」标记，避免重复添加。
- 修复"选图器关掉后仍在后台继续翻页"（现在关闭即停止，并加 40 页上限、内存缓存最多留 6 项）。
- 修复"添加队列期间切换类型/游戏会把图加错地方"（入队即固定上下文）。
- 「关于」新增可点击的 GitHub 项目主页 / Releases 链接（作者也是链接）。
- 修复“把图删除后仍提示『这张图已加入库』、不让重新添加”：改为**实时查库**判断，
  删除后即可重新添加（竖版/横版/大背景/Logo/图标 均修复）。

Linux 版
- 支持 `.gameart` 文件关联：**默认自动关联**（启动即写好，无需手动点），双击 `.gameart` 即可打开；Windows 用注册表、Linux 用 freedesktop 标准，都不需要管理员/root。
- Linux 上 `.gameart` **有专属图标**了（多尺寸，取自应用的 .gameart 图标）。修复要点：MIME 图标名必须把 `application/x-gameart` 里的 `/` 换成 `-`——**文件路径与 XML 里的 `<icon>` 名称两处都要**（曾因 XML 名写成带斜杠而导致一直显示默认图标）。
- 正式发布：Linux AppImage 已作为 **v0.88 正式 Release 附件**（与 Windows 便携包并列），README 增加 Linux 下载/安装说明（中英双语）。
- 修复「图标」一直无效：官方 Steam 游戏的图标不在 config\grid，而在 Steam 的图标缓存
  （appcache/librarycache）。现在会正确写入该缓存（只替换哈希命名的图标文件，
  原子写入 + 自动备份，不影响同目录的其它库资源）；非 Steam 快捷方式仍写 config\grid。
  注意：图标需**重启 Steam** 后才会显示。

Linux 版（开发中，见维护文档 §18）
